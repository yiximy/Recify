## 变更摘要

实现「比对关联模式」7 项功能增强（委托 Codex 窗口模式实现 + Claude Code 深度审查）：

1. **父行「取消所有关联」**：已关联文件/组合父行右键提供，带确认框，逐个解除后实时刷新
2. **多选组合**：`ExtendedSelection` 支持 Ctrl 多选，右键「组合」命名创建组合父行，默认展开
3. **组合批量关联**：组合父行 ↔ 单文件/组合，成员两两 `batch_link`
4. **组合金额实时计算**：组合父行金额列显示成员总和（round 2），成员变动自动重算
5. **组合自动对比**：`get_amount_matches` 支持 组合↔单文件 / 组合↔组合
6. **二级界面组合优化**：右键组内文件「取消关联/添加关联」
7. **关联项组合显示**：二级界面改为「关联组N」容器，单文件也包组、可拖动换组、空组保留、同步滚动
